# v0.2.0 — Verified report claims

This release checks every published evaluation claim against frozen evidence and
policy. Edited JSON can no longer remove a requested comparison, invent a
supported cost, or change an unsupported decision without rejection.

## Changes

- `report` reconstructs claims with fresh scoring and an independent oracle
  check before rendering. Its exit code uses the same verified snapshot that
  was published, even if the supplied file changes afterward.
- Equivalent known-offset run-window timestamps compare by represented instant.
  Raw evidence stays unchanged; unknown offsets and genuine mismatches retain
  their qualifications.
- Output path aliases preserve complete publication and rollback behavior.
  Malformed/overflowing JSON fails with structured diagnostics.
- A separate standard-library study-log checker retains every assignment and
  unsuccessful attempt, independent grading, setup/repeat work and machine time.
  Its synthetic tests do not represent a human study.

## Compatibility

`report` now rescores and independently verifies; it no longer promises rendering
without rescoring. The Python `write_json_artifacts` API now requires `run`.
CLI forms and canonical schema version remain unchanged. Invalid inputs exit 2
before publication, legitimate blocked reports exit 3, and eligible/unrequested
comparisons or valid arm threshold failures exit 0.

## Evidence and limits

The local suite passes **233 tests with zero skips**. Fresh pinned NEEDLE replay
and independent checks agree on all **1,956 assignment ranks**. Both real packets'
JSON/HTML artifacts reproduce exactly and remain byte-identical to the released
baseline. The new 23-case derived-report mutation catalog is known development
regression material, not an independent holdout. The failed v1 and separately
reserved v2 validation histories remain unchanged.

Historical provider comparisons remain **blocked** because actual collection
conditions are missing. Costs and exact physical request counts remain unknown.
The historical preparation experiment remains **neutral**. Reviewer workflow
benefit is **unassessed**: no authorized reviewer study or operating requirements
are available. No provider winner or purchasing recommendation is claimed.
