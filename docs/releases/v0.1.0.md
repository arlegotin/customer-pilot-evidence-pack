# v0.1.0 — Customer Pilot Evidence Pack

First public release of a local Python tool that turns retrieval evaluation
files into an inspectable pilot evidence report.

The CLI imports NEEDLE Scholar or canonical JSONL, freezes source provenance,
preserves assignments and physical attempts, scores known-item retrieval,
checks independent references, gates comparisons, and writes JSON/static HTML.
Product commands use Python 3.11+ and the standard library. No provider API,
model judge, server or upload is required.

## Measured result

- Two real packets: 649 distinct queries and 160 source groups after deduplication.
- Supported native/oracle agreement across 1,956 assignment ranks.
- 202 software tests; validation v2 detects 20/20 introduced faults (12/12
  critical), with eight healthy controls and zero unexpected findings.
- Offline reproduction preserves canonical records, normalized digests and
  evaluation/verdict/HTML bytes. Earlier failed validation remains recorded.
- Workflow value is **neutral**: the reusable baseline also handled packet B
  through configuration, so preparation savings were not demonstrated.

Both real provider comparisons remain **blocked** because actual comparison
conditions are missing. Exact request counts and costs remain unavailable.
Retrieval hits do not establish answer quality or citation support. Browser/human
visual review remains unperformed.
